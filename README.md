# Deep Thoughts

Veřejná znalostní knihovna propojená s ChatGPT. Karty jsou otevřené, diskuse v ChatGPT se automaticky nezveřejňují.

## Co zde najdeš
- [Katalog karet](index.json) — metadata pro procházení a vyhledávání
- [Filozofie](cards/philosophy/DT-000001.md) · [Psychologie](cards/psychology/DT-000002.md) · [Historie](cards/history/DT-000003.md) — první tři ukázkové karty
- [Oblíbené](library/favorites.json) — seznam označených ID
- [Poznámky](notes/README.md) — místo pro dobrovolně publikované osobní úvahy
- [Datový model](docs/data-model.md) — formát a pravidla

## Použití přes ChatGPT
- „Najdi v Deep Thoughts karty o stoicismu.“
- „Otevři DT-000001 a proberme ji.“
- „Označ DT-000001 jako oblíbenou.“
- „Ulož následující poznámku veřejně ke kartě DT-000001: …“

Oblíbené a poznámky se zatím upravují pomocí explicitních požadavků v ChatGPT, nikoliv samostatným webovým rozhraním.
